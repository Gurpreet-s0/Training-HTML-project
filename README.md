# Training HTML Project

This is a more complex web application created as part of an HTML training project. It consists of multiple pages with interactivity and responsive design.

## Project Structure

- `index.html` - Home page
- `about.html` - About page
- `contact.html` - Contact page with form
- `assets/css/style.css` - Stylesheet for the entire site
- `assets/js/main.js` - Main JavaScript for interactions
- `assets/js/contact-form.js` - JavaScript for contact form validation
- `assets/images/` - Directory for images (currently contains placeholders)

## Features

- Responsive design that works on mobile and desktop
- Navigation menu active state highlighting
- Interactive feature cards with hover effects
- Contact form with client-side validation
- Modern CSS with gradients, transitions, and flexbox/grid layouts
- Accessible semantic HTML

## How to View

Simply open any of the HTML files in a web browser. For the full experience, open `index.html` and navigate through the site.

## Customization

Feel free to modify the content, styles, and scripts to suit your training needs. Replace placeholder content with your own text and images.

## Training Notes

This project demonstrates:
- HTML5 semantic elements
- CSS3 features (flexbox, grid, transitions, transforms)
- JavaScript DOM manipulation and event handling
- Form validation
- Responsive design principles
- File organization for a multi-page website

Enjoy your training!
